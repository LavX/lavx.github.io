Open source

Tools I wrote because I needed them.

Subtitle automation for media servers, an installer that wires a whole media stack in one pass, Windows drivers for the Steam Deck, an LLM translation API, and a few small services. Mostly Python, TypeScript and C#. All of it is on GitHub.

Subtitles and media

Eight projects

Most of this started with one problem: subtitles that arrive late, in the wrong language, or timed to a different cut of the film.

Bazarr+

Python

A hard fork of Bazarr for Sonarr, Radarr, Plex and Jellyfin. Provider Hub plugin catalog, a multi-tenant subtitle API for other apps, bilingual subtitles, AI translation through OpenRouter, multi-engine sync, and no telemetry.

arrstack

TypeScript

Single-binary TUI installer that sets up and auto-wires a twelve-service media stack on a clean Linux host in about ninety seconds.

ai-subtitle-translator

Python

Subtitle translation API over OpenRouter, covering 300+ models. Async job queue, adaptive batch sizing, live progress and cost tracking.

bazarr-provider-catalog

Python

Sixty-plus subtitle scrapers as installable plugins, so a broken provider is fixed without waiting for a release. Stdlib-only, hash-locked, worker-isolated.

opensubtitles-scraper

Python

Self-hosted OpenSubtitles.org scraper with a Bazarr-compatible API, replacing the provider that was removed. Handles Cloudflare and Anubis proof-of-work.

bazarr-mcp

Python

Model Context Protocol server for Bazarr+. Lets an AI assistant search subtitles, find a quote across episodes and operate the instance.

jellyfin-plugin-bazarr-plus

C#

Jellyfin 10.11+ subtitle provider that proxies search and download to your own Bazarr+ over its OpenSubtitles-compatible API.

vlsub-bazarr-plus

Lua

VLC extension that pulls subtitles from your Bazarr+ instead of a public provider.

Windows on handhelds

Two projects

Running Windows on a Steam Deck means fighting the driver set. These are the two pieces that were missing.

deck-driver-manager

C#

Pick between Valve's OEM graphics driver and a locally patched AMD build, and keep the rest of the Deck's drivers straight.

DeckLux

PowerShell

Open ambient-light sensor driver for the Steam Deck on Windows, so auto-brightness works at all.

Small services

Three projects

Tiny APIs, built for the moments an interface has to say something and there is nothing useful to say.

yes-as-a-service

Python

Returns a random affirmation. The counterpart to the original no-as-a-service.

error-as-a-service

Python

Returns a random error message, for when you need a graceful way to fail.

quip-as-a-service

Python

Returns a random quip, built for loading screens and placeholders.
